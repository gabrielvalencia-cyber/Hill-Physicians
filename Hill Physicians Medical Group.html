Layer 1 · Infrastructure You choose the perimeter

On-premises, Unframe-hosted, or your own cloud — you choose where it runs. In customer-hosted mode, Unframe has zero access to your environment. No data ever leaves unless you decide it does.

Layer 2 · Agent guardrails Rules enforced by the platform, not model judgment

Every agent operates with a typed data contract that defines what it can access, what actions it can take, and what rules require human approval. Those rules are enforced at the platform layer — never delegated to the model.

Layer 3 · User & data governance The most granular layer of control

Configurable independently of infrastructure and agent settings. Data — what an agent can see. Agent — what an agent can do. User — who did what, and the proof.

Control what AI can see
Scoped, credentialed access — no ambient access to the wider environment.
Knowledge Fabric & managed memory — each agent's memory stays isolated.
PII boundaries & masking — sensitive data redacted automatically before exposure.
End-to-end encryption — at rest and in transit, across every connected source.
Control what AI can do
Deterministic steps & gates — critical steps run as fixed, auditable logic.
Human-in-the-loop — gated actions wait for a named approver; nothing proceeds on its own.
Governed registry — every agent and tool is registered, certified, and audited.
AI security — built-in defenses against prompt injection, jailbreaks, and adversarial inputs.
Control who can use AI — and how
Role-based access & two-tier admin — super-admins set tenant policy, unit admins govern their scope.
Policy enforcement in the moment — out-of-scope actions are blocked as a logged decision, never silently overridden.
Audit-ready evidence — every run exports policies evaluated, PII boundary, and human approval.
